1. Cargar dataset
2. Preprocesarlo en varias formas
3. entrenar modelos
4. evaluar modelos
   1. entender los resultados de cada modelo y explicarlos
5. comparar resultados
6. volver a procesar en otras formas
7. entrenar modelos
8. evualuar modelos
9. comparar estos resultados con los anteriores
